# Professor Management System 

This project is a simple University Professor Management System developed using C++ programming language.

The system allows the professor to log into the program using a username and password. After logging in, the professor can manage student information through a simple menu-driven interface.

The system includes several functions such as:
- Adding student information
- Displaying student records
- Entering student grades
- Determining whether the student passed or failed

The project was developed using important programming concepts including:
- Functions
- Arrays
- Pointers
- Loops
- Conditional statements

Pointers were used to access and manage student data inside the functions. The project aims to provide a simple example of how programming can be used to organize academic information in an efficient way.
